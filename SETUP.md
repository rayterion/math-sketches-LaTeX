


# Required setup

1. install [TeX Live](https://www.tug.org/texlive/) (or [MikTeX](https://miktex.org/) on Windows)
2. install [VS Code](https://code.visualstudio.com/) and the [LaTeX Workshop extension](https://marketplace.visualstudio.com/items?itemName=James-Yu.latex-workshop)
3. install [Perl](https://www.perl.org/) (for running the `build.sh` script) and add it to your PATH
